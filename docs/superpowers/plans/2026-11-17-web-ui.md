# txt2book 界面与预览 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在核心库之上做出可用的单页界面：登录、上传、目录树编辑、封面、主题预览、导出，并保证预览与导出一致。

**Architecture:** 状态集中在 `useBookSession` composable（可单测），组件只负责展示与事件转发；预览用 `<iframe srcdoc>` 注入与导出同源的 `renderPreviewDocument`。

**Tech Stack:** Vue 3 Composition API、Vite、Vitest + @vue/test-utils + happy-dom。

**Spec:** `docs/superpowers/specs/2026-11-17-txt2book-design.md`

## Global Constraints

- 依赖核心计划：`src/types/book.ts`、`src/core/*`、`src/core/converters` 的接口见索引文档，不重复定义。
- 所有样式写在 `src/styles/app.css` 与 `src/styles/tokens.css`，组件内不写内联样式，不使用 `<style scoped>` 之外的方式。
- 用户可见文案中文。
- 不写 `git commit`。
- 未登录时只渲染登录页。

## Review Focus

- 删除后选中项悬空，预览面板空白或崩溃。
- 切换编码后章节编辑结果被静默丢弃。
- 预览 iframe 的主题 CSS 泄漏到应用主界面。
- 封面接口失败时界面卡在 loading 状态。
- 移动端窄屏下三栏重叠、按钮不可点。

```ts
import { describe, expect, it } from "vitest";
import { useBookSession } from "../src/composables/useBookSession";

function seed() {
  const s = useBookSession();
  s.loadBook(
    { title: "书", author: "", language: "zh-CN" },
    {
      volumes: [{ id: "v1", title: "第一卷", kind: "volume" }],
      chapters: [
        { id: "c1", title: "一", kind: "chapter", lines: ["a"], volumeId: "v1" },
        { id: "c2", title: "二", kind: "chapter", lines: ["b"], volumeId: "v1" },
      ],
    },
    "书",
  );
  return s;
}

describe("useBookSession", () => {
  it("selects the first chapter after load", () => {
    expect(seed().selected.value?.id).toBe("c1");
  });
  it("moves selection to a neighbor after deleting the selected chapter", () => {
    const s = seed();
    s.select("c2");
    s.removeChapter("c2");
    expect(s.selected.value?.id).toBe("c1");
  });
  it("keeps selection valid after undo", () => {
    const s = seed();
    s.removeChapter("c1");
    s.undo();
    expect(s.book.value.chapters).toHaveLength(2);
    expect(s.selected.value?.id).toBe("c1");
  });
  it("clears selection when the book becomes empty", () => {
    const s = seed();
    s.removeChapter("c2");
    s.removeChapter("c1");
    expect(s.selected.value).toBeNull();
    expect(s.hasBook.value).toBe(false);
  });
  it("updates metadata without touching chapters", () => {
    const s = seed();
    s.updateMeta({ author: "作者" });
    expect(s.book.value.meta.author).toBe("作者");
    expect(s.book.value.chapters).toHaveLength(2);
  });
});
```

`tokens.css` 定义：`--bg`、`--surface`、`--border`、`--text`、`--muted`、`--primary`（深墨绿 `#1f5c4a`）、`--primary-soft`、`--danger`、`--radius`、`--shadow`、`--space-*`。`app.css` 提供 `.card`、`.btn`、`.btn-primary`、`.btn-ghost`、`.field`、`.empty`、`.loading`、`.toast` 与响应式断点（`<= 980px` 单列）。
